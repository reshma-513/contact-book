# 📒 Contact Book

A simple and user-friendly **Contact Book application developed using Python**.
This project allows users to store, view, search, update, and delete contact information.

## 🚀 Features

* ➕ Add new contacts
* 📋 View all contacts
* 🔍 Search for a contact
* ✏️ Update existing contact details
* 🗑️ Delete contacts
* 💾 Store contact information
* 🖥️ Simple command-line interface

## 🛠️ Technologies Used

* **Python 3**
* Python standard libraries
* Command Line Interface (CLI)

## 📂 Project Structure

```text
contact-book/
│
├── main.py
├── README.md
└── requirements.txt
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/contact-book.git
```

### 2. Open the project folder

```bash
cd contact-book
```

### 3. Run the application

```bash
python main.py
```

If `python` does not work, try:

```bash
py main.py
```

## ▶️ How to Use

After running the program, follow the options displayed in the terminal.

For example:

```text
========================
      CONTACT BOOK
========================

1. Add Contact
2. View Contacts
3. Search Contact
4. Update Contact
5. Delete Contact
6. Exit

Enter your choice:
```

Select the required option and enter the requested contact information.

## 💡 Example

A contact may contain information such as:

```text
Name     : Rahul
Phone    : 9876543210
Email    : rahul@example.com
```

The user can later search, update, or delete the contact.
